# Experimental AOSP rebuild of remaining JARs

Use a Linux AOSP build host. Initialize a fresh checkout using
`repo init --partial-clone -u https://android.googlesource.com/platform/manifest -b android-16.0.0_r3`
and `repo sync -c`. See https://source.android.com/docs/setup/start/requirements .

Run `bash scripts/rebuild-aosp-jars.sh /path/to/aosp /path/to/output` from Prime.
The script records the resolved manifest and output SHA-256 hashes. It checks
the frameworks/base tag, but does not independently verify all checkout
revisions or local modifications. Use a clean checkout. If the tag ref is
absent, fetch the official tag before running.

Compare class inventories, APIs and hashes against existing inputs; test all
three Prime variants. Never commit generated binaries. This script is an
unexecuted candidate recipe, not an integrated F-Droid build. The current
four tracked JARs remain until the source recipe and build integration are
validated. F-Droid custom compilation belongs in the build phase, after
source scanning; discuss build host requirements with the reviewer.

SystemUI-statsd is generated by stats-log-api-gen from the sysui module
(see frameworks/base/packages/SystemUI/shared/Android.bp).
